# Gym Progress and Workout Tracking System

## Description
This project is a gym tracking system that allows users to log workouts, track exercises, and monitor progress over time using a structured MySQL database.

The system is built using:
- Python (Flask)
- MySQL
- HTML

## Features
- Add and view users
- Create workout sessions
- Log workout entries (sets, reps, weight, rest time)
- Track exercises
- View statistics (total volume, personal records, progress)

## Database
The database consists of the following tables:
- Users
- WorkoutSession
- WorkoutEntry
- Exercise
- Goal
- BodyMeasurement
